# TV Doctor

Android-приложение для телефона, которое по Wi‑Fi (ADB по сети) подключается к Android TV, Google TV или ТВ-приставке и:

- **сканирует систему**: память, место на диске, температуру, нагрузку процессора, все приложения (включая системные);
- **находит лишнее**: рекламные и телеметрические модули, предустановленный мусор, «прожорливые» фоновые приложения, большой кэш;
- **исправляет в один тап**: отключить, удалить для пользователя, остановить, запретить работу в фоне, очистить кэш/данные;
- **убирает рекламу**: отключение рекламных пакетов + Private DNS с фильтром (AdGuard, Mullvad, Control D или свой);
- **лаунчер и настройки**: выбор лаунчера по умолчанию, отключение стандартного лаунчера с рекламой, скорость анимаций, редактор любых `settings` (global / secure / system), консоль ADB;
- **слежка**: кто имеет доступ к камере и микрофону, когда последний раз пользовался, кто использует их прямо сейчас; службы спецвозможностей, доступ к уведомлениям, администраторы устройства, клавиатура; запрет доступа в один тап;
- **журнал с отменой**: каждое изменение записывается вместе с обратной командой, отменить можно по одному или всё сразу; есть кнопка «вернуть все отключённые приложения».

Важные системные компоненты (System UI, настройки, Google Play Services, текущий лаунчер, драйверы производителя и т.п.) защищены от отключения. Снять защиту можно в «Ещё → Экспертный режим».

Приложение ничего не отправляет в интернет: всё читается напрямую с телевизора.

## Установка

1. Откройте [Releases → latest](../../releases/tag/latest) на телефоне и скачайте `TVDoctor.apk`.
2. Разрешите установку из этого источника и установите.

APK собирается автоматически GitHub Actions при каждом изменении в `main` (вкладка **Actions**).

## Подключение к телевизору

1. На ТВ: **Настройки → Система → Об устройстве → «Сборка»** — нажмите 7 раз, появится режим разработчика.
2. **Настройки → Система → Для разработчиков**: включите **«Отладка по USB»** (и **«Отладка по сети / ADB по сети»**, если пункт есть).
3. Узнайте IP телевизора: **Настройки → Сеть и Интернет → ваша сеть**.
4. В приложении введите IP (порт 5555) или нажмите **«Найти телевизор в сети»** → **«Подключиться»**.
5. На ТВ появится «Разрешить отладку?» — отметьте **«Всегда разрешать»** и нажмите **ОК**.

**Если на ТВ есть только «Беспроводная отладка» с кодом сопряжения** (некоторые Google TV на Android 11+): один раз с компьютера выполните
`adb pair IP:порт_сопряжения`, затем `adb connect IP:порт` и `adb tcpip 5555` — после этого приложение подключается на порт 5555 до перезагрузки ТВ.

Приложение можно поставить и на сам телевизор (оно есть в лаунчере) и подключиться к `127.0.0.1`.

## Как это работает

- ADB-клиент — библиотека [dadb](https://github.com/mobile-dev-inc/dadb); ключ RSA генерируется и хранится в приложении.
- Все действия — обычные команды `adb shell`: `pm disable-user --user 0`, `pm uninstall -k --user 0` (возвращается `cmd package install-existing`), `am force-stop`, `cmd appops set … RUN_ANY_IN_BACKGROUND ignore`, `pm trim-caches`, `settings put`, `pm revoke`, `appops set`, `cmd package set-home-activity`.
- Ни одна из этих команд не меняет прошивку: после сброса ТВ к заводским настройкам всё вернётся.

## Сборка

Откройте проект в Android Studio или выполните `./gradlew assembleRelease`. Ключ подписи `keystore/tvdoctor.jks` (пароль `tvdoctor`) лежит в репозитории, чтобы каждая сборка ставилась поверх предыдущей; для публикации в магазинах замените его своим.

Код: `app/src/main/java/app/tvdoctor/` — `core/` (разбор вывода команд, база известных пакетов, сканер, команды с отменой; покрыто тестами), `adb/` (подключение и поиск в сети), `ui/` (экраны).
